# geteduroam documentation

Documentation [Hugo](https://gohugo.io) site

Make sure you have [Hugo installed](https://gohugo.io/getting-started/installing/).

* Test with `make dev`
* Generate `public/` with `make public`

Then just upload the `public/` directory to a webserver.

Some images and stylesheets are copied from the **letswifi-profile** project.
